# Проект лабораторных работ 1–7 на C++

## Лабораторная работа №1
КЛАССЫ. КОНСТРУКТОРЫ. ДЕСТРУКТОРЫ.  
Данная программа предназначена для выполнения основных операций с математическими векторами произвольной размерности. Она позволяет складывать векторы, умножать их на действительное число, вычислять норму и выполнять нормирование – приведение длины вектора к единице.  
При запуске программы пользователю будет предложено ввести размерность исходных векторов, а также значения, которыми они будут заполнены. После этого программа выводит оба вектора и выполняет их сложение, результат показывается на экране.  
Далее необходимо ввести действительное число, на которое будет проведено умножение векторов и их суммы. Результат операции отображается в виде отдельных векторов с вычисленными компонентами.  
На следующем этапе программа выполняет нормирование каждого вектора, то есть делит каждую компоненту на его длину, чтобы получить единичный вектор.  
Программа завершает работу автоматически после выполнения всех операций.

## Лабораторная работа №2
ИСПОЛЬЗОВАНИЕ УКАЗАТЕЛЕЙ В C++  
Данная программа предназначена для выполнения операций с двумерной матрицей, включающих поиск максимального и минимального элементов, определение их адресов в памяти и обмен строк, в которых они расположены.  
При запуске программы пользователю будет предложено ввести количество строк и столбцов матрицы, после чего необходимо заполнить все элементы матрицы числовыми значениями. Далее программа автоматически находит минимальный и максимальный элементы, определяет строки, в которых они находятся, и выводит их значения вместе с адресами памяти.  
Затем происходит обмен строк местами: строка с минимальным элементом меняется с той, где находится максимальный. Происходит перестановка и на экран выводится обновлённая матрица.  
Результаты отображаются в табличном виде, а адреса памяти в шестнадцатеричном формате. Для завершения работы достаточно закрыть окно программы.

## Лабораторная работа №3
ДИНАМИЧЕСКОЕ СОЗДАНИЕ ЭКЗЕМПЛЯРОВ. ИСПОЛЬЗОВАНИЕ ОПЕРАЦИЙ NEW, DELETE  
Программа предназначена для выполнения операций с динамической последовательностью целых чисел. Её основная задача – анализировать элементы последовательности и преобразовывать их в зависимости от заданного условия. Если в последовательности присутствует хотя бы одно число меньше 10, все отрицательные элементы заменяются их квадратами. В противном случае, когда все значения больше или равны 10, каждый элемент последовательности удваивается.  
После запуска программы пользователю предлагается ввести количество элементов последовательности. Затем появляется меню, в котором можно выбрать способ заполнения данных: вручную, вводя каждое число с клавиатуры, либо автоматически.  
После ввода данных программа выводит исходную последовательность на экран, выполняет обработку в соответствии с условием и отображает результат после преобразований.  
Для завершения работы программы достаточно дождаться вывода результатов и закрыть окно.

## Лабораторная работа №4
НАСЛЕДОВАНИЕ. ВИРТУАЛЬНЫЕ ФУНКЦИИ.  
Данная программа предназначена для выполнения основных операций над математическими векторами произвольной размерности, таких как сложение, умножение на действительное число, вычисление нормы и нормирование. В отличие от предыдущего варианта, программа использует виртуальные функции и производный класс VChild, демонстрирующий принципы наследования и полиморфизма.  
После запуска программы пользователю будет предложено ввести размерность векторов и значения, которыми будут заполнены их компоненты. На основе этих данных создаются объекты класса VChild. Программа выводит оба созданных вектора и выполняет их сложение. Результат отображается на экране.  
Затем пользователю необходимо ввести действительное число, на которое программа умножит оба исходных вектора. Полученные результаты будут представлены в виде отдельных векторов.  
На следующем этапе производится нормирование каждого вектора. Нормирование приводит длину вектора к единице путём деления каждой его компоненты на норму.
Все расчёты выполняются через виртуальные функции, переопределённые в классе VChild, что отображается в выводе программы.  
После выполнения всех операций программа завершает работу автоматически.

## Лабораторная работа №5
ПЕРЕГРУЗКА ОПЕРАТОРОВ. ПЕРЕГРУЗКА ФУНКЦИЙ  
Данная программа предназначена для выполнения основных операций над математическими векторами: сложения, умножения на действительное число, вычисления нормы и нормирования.  
После запуска пользователю предлагается указать размерность вектора и два значения, которые будут использованы для заполнения компонентов. Созданные объекты инициализируются при помощи перегруженной функции Init(), что отображается в виде сообщения на экране.  
Далее программа выводит оба исходных вектора и выполняет их сложение. Операция сложения выполняется через перегруженный оператор+, о чём также выводится сообщение. Результат отображается в виде нового вектора.  
Затем пользователь вводит число, на которое будут умножены оба вектора. Для выполнения операции используется перегруженный оператор *, а все промежуточные вычисления выводятся пользователю.  
После этого программа нормирует векторы. Нормирование приводит длину вектора к единице путём деления каждой его компоненты на величину нормы. В случае невозможности нормирования (норма равна нулю) программа уведомляет об этом пользователя.  
Все результаты выводятся сразу после выполнения соответствующих операций. Для завершения работы достаточно закрыть окно программы.

## Лабораторная работа №6
ШАБЛОНЫ КЛАССОВ И ФУНКЦИЙ  
Данная программа предназначена для работы с наборами целых и вещественных чисел. Пользователю предлагается сначала выбрать тип данных: целые числа или вещественные.  
После выбора типа необходимо ввести количество элементов набора, а затем сами значения. Для целых чисел предусмотрена проверка корректности ввода, чтобы исключить ошибочные данные.  
На основе введённых данных создаются объекты класса Variance. Для целых чисел используется обычный класс, а для вещественных чисел – шаблонный класс.  
Программа вычисляет среднее арифметическое набора и дисперсию по формуле:  
1/(n-1) ∑_(i=1)^n▒〖(x_i 〗-(x ) )², где (x )  – среднее арифметическое этих чисел.  
Результаты вычислений выводятся на экран с точностью до дробной части. После выполнения всех операций программа завершает работу автоматически.

## Лабораторная работа №7
ШАБЛОНЫ КЛАССОВ И ФУНКЦИЙ  
Программа демонстрирует работу с потоками ввода-вывода. После запуска программы пользователю предлагается ввести набор значений: одно вещественное число, символ и целое число, а затем два дополнительных символа. Полученные данные автоматически сохраняются объектом класса Formatter. Далее программа выполняет вывод данных в заранее определённой последовательности, применяя различные элементы форматирования: ширину поля, заполняющий символ, изменение точности и переключение системы счисления.  
Все результаты отображаются на экране, а затем дублируются в текстовый файл, который создаётся автоматически. После завершения всех операций программа закрывает файл и завершает выполнение.
